# 猜价格游戏 — 需求说明

> 状态：功能完成，真实产品已导入。界面细节和最终题目选择可再调整。

## 游戏规则（来自活动原始说明）

- 5 道菜：1 道前菜、2 道主菜、2 道甜点。每道菜一页，列出 3～6 种主要食材。
- 每桌猜这道菜所有食材的**总价**。
- **最接近但不超过**真实价格的一桌赢得这一轮（The Price Is Right 规则）。
- 赢得轮数最多的一桌获得奖品。

## 现场形式

- 15 桌，**每桌一部手机**，扫码进入，不用装 App、不用注册。
- 大屏（投影/电视）显示二维码、菜品、倒计时、揭晓结果和排行榜。
- 主持人在大屏页面底部的控制栏操作（空格键 = 主按钮）。

## 每轮流程

```
等待 →[开始]→ 菜品出现 + 15 秒倒计时 →[时间到，服务器自动锁定]→ 锁定 →[揭晓]→ 显示结果 →[下一步]→ 排行榜 / 下一轮
```

- 菜品和倒计时**同时出现**：之前没人见过题目，无法提前查价。
- 截止时间由服务器判定（另有 0.75 秒网络宽限），改手机时间无效。
- 主持人可以提前结束本轮（所有桌都答完时），也可以重做本轮。
- **揭晓前，真实价格不会发送到任何手机或浏览器。**

## 计分

- 金额以"分"为单位存成整数（30.75 → 3075）。
- 输入支持 `30.75`、`$30.75`、`30,75`、`30`，最多两位小数。
- 报价 > 真实价格：本轮无效。有效报价中最高者得 1 分。
- 总排名按赢的轮数；同分者排名相同。

## 开场（大屏，主持人按空格翻页，← 返回）

1. **扫码页**：二维码和网址，以及各桌加入情况。
2. **欢迎页**：PC Insiders Report Holiday 封面扇形展开，标题 "Guess the Price! Holiday Edition"。
3. **规则页**：4 张卡片（每桌一部手机 / 15 秒 / 不能超过 / 赢最多轮），配一个例子。
4. 再按空格开始练习第 1 轮。

开场时，手机上显示欢迎语和 4 条规则。界面统一用 Holiday Insiders Report 风格：白字、金色价格、青柠绿标出赢家。

- **大屏背景**：经典圣诞风格，用代码绘制，任何尺寸的屏幕都清晰。四种浓郁底色（品牌洋红、酒红、常青绿、午夜蓝）每换一屏轮换一种，配淡金色雪花、柔和光点和金色细边框。备选方案是虚化的 Insiders 封面照片，在主持人网址后加 `?bg=photo` 即可切换；封面原图只有约 660 像素宽，不虚化放大会糊。手机用洋红斜纹背景。
- **倒计时音乐**：只在主持人电脑上播放，由浏览器现场合成，没有音乐文件、不占服务器。**每一题换一首传统圣诞歌**（均为公有领域）：Jingle Bells、Deck the Halls、We Wish You a Merry Christmas、God Rest Ye Merry Gentlemen、Good King Wenceslas、Joy to the World，按顺序轮换。编排成快节奏欢快的乐队：旋律，加上"嘭-嚓"鼓点、跳跃低音、反拍和弦和雪橇铃，速度每分钟 168～200 拍。最后 5 秒加入滴答声，时间到响蜂鸣，揭晓时安静。主持人如果提前按 Stop，音乐立即停止并响蜂鸣。按 **M** 静音。输出端装了限幅器，避免在场地音响上爆音。
- 倒计时数字下面写着 "seconds left"。

## 练习轮

- 正式比赛前先玩 **2 轮练习**（`practice`），让大家熟悉扫码、输入、揭晓的流程。
- 练习照常揭晓价格和"本来会赢的桌"，但**不计分**、不进排行榜。
- 练习结束后，大屏和手机显示"Practice over — from now on it counts!"，然后进入正式第 1 轮。
- 主持人可以随时按 **Skip practice** 跳过剩下的练习，直接开始正式比赛。
- 练习题数量可配置，`practice: []` 表示不练习。

## 轮数

- 正式轮数 = `dishes` 里的题目数量，可随时改，比如时间不够就改成 3 轮。
- 练习轮数 = `practice` 里的题目数量。

## 总冠军平局：加赛

5 轮后如果两桌或以上并列第一（15 桌水平相近时约一半的机会），主持人按空格开始**加赛**：

- 只有并列的桌参加，其他桌手机显示"观战"，不能作答。
- 1 道加赛题（`tiebreaker`），同样 15 秒。
- 判定顺序：
  1. 最接近但不超过者赢；
  2. 如果并列的桌全部超价 → 离真实价格最近者赢；
  3. 如果仍然无法分出（最高有效价相同、距离相同，或都没作答）→ 系统当场随机抽签。
- 没作答的桌算输。
- 加赛只决定冠军，不改变 5 轮的得分。加赛只进行一次，不会无限加下去。
- 建议另外准备一道后备题，以防加赛题临时出问题需要替换。

## 题目内容

题目是 16 个 President's Choice 产品，来自 `Candidate_Items.pptx` 和 `item_list_and_price.xlsx`。表格里的价格已和幻灯片上的价格逐一核对，16 个全部一致。

- **玩法改为直接猜产品售价**，提示语为 "Guess the shelf price of this item (before tax)."
- **图片**：从太太的幻灯片里取出每个产品的包装图和美食图（不包括带价格的商品卡片），在大屏上做成拼贴：包装图放大，美食图斜着叠在旁边。PowerPoint 里被裁掉的部分也逐一检查过，没有价格。
- **手机**只显示产品名和规格（例如 288 g），不显示图片。

### 需要组织者确认

- **3 个产品当时在打折**，表格用的是折扣价：Beef Chili 与 Tomato Basil Bisque 都是 $7.50（原价 $9.00），TidyStack 是 $20.00（原价 $21.00）。目前的选择避开了这 3 个。
- **"before tax"**：Skillet、Charcuterie Board、Truffles 在商品卡片上注明 "Plus tax"。规则统一按税前货架价。
- 第 17、18 张幻灯片（Insiders Report 封面、节日礼篮）不是产品，没有使用。

## 异常处理

| 情况 | 处理 |
|---|---|
| 手机刷新 / 断线 / 锁屏后回来 | 自动重连，桌号和本轮报价都保留 |
| 手机没电，换一部手机 | 主持人在大屏上点击该桌号 → 释放 → 新手机重新选桌 |
| 两部手机抢同一个桌号 | 先到先得，后来的提示"已被占用" |
| 主持人页面刷新 | 游戏状态存在服务器上，不会丢 |
| 彩排结束后清场 | Reset game → 第二个确认框选 OK，所有桌需要重新选桌 |
| 现场网络差 | 程序无法解决：活动前必须在现场实测；准备纸卡作为后备 |

## 技术架构

- Cloudflare Workers（免费版）+ 一个 Durable Object 作为唯一的游戏房间。
- Durable Object 保存状态、用 alarm 执行截止锁定、通过 WebSocket 把状态推送给所有屏幕和手机（Hibernation API）。
- 前端：纯 HTML + JavaScript，无框架、无构建步骤。
- 主持人页面用密钥保护（服务器 secret `HOST_KEY`）。
